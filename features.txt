TV Dashboard — Feature List
Version 0.4.19

═══════════════════════════════════════
DASHBOARD PAGE
═══════════════════════════════════════
- Stat row (5 cards): shows watched, hours watched, avg rating, episodes
  watched, completion rate — icon badge + colored top border + shadow;
  colors from theme.chartColors[] for count stats, ratingColor()/
  completionColor() for the 2 value-driven ones, flex-wrap layout
- Highlights row (3 cards): Most Watched, Top Rated, Newest Release —
  poster + name + detail, click through to Show Detail
- Continue Watching: shows with partial completion (< 100%); "New eps"
  tag on cards whose show status is "Returning Series"
- Recently Watched: last 3 entries from CSV (row-order based)
- Sidebar tabs: Top Genres / Watch Status / Ratings (rating-distribution
  mini bar chart), icon-labeled
- Not Started: compact clickable list, unwatched sorted by rating;
  "All caught up" fallback card when every show has been started
- Explore More CTA row: links to Shows and Statistics pages
- All poster thumbnails fall back to placeholder on empty OR broken/404 URL
- Every clickable card keyboard-operable (role="button", Enter/Space)
- Avg Rating card neutral-colored when no shows are rated
- Empty state (Empty + Refresh) when CSV has 0 rows

═══════════════════════════════════════
SHOWS PAGE
═══════════════════════════════════════
- Responsive poster grid: 2–8 columns based on viewport width
- Default sort: Recently Watched (CSV row order, newest first)
- Sort options: Recently Watched, Rating, Popularity, Year, Watch Time, Name A–Z
- Search: matches title, actor/actress, keyword, genre, creator, network
  (search text lowercased once per data load, not per keystroke)
- Filter by genre (multi-select) and status — both option lists built from
  the loaded CSV (no options that always give 0 results); statuses in a
  fixed order (Returning Series, Ended, Canceled, …), unknown ones last
- Filter bar in a themed Card (shadow + radius); result-count row
  ("X of Y shows") with closable filter chips and a Reset filters link
- All filters + sort persist across sessions via localStorage; last change
  flushed on navigate-away; saved genres/statuses no longer in the CSV are dropped
- Pagination with configurable page size (12/24/48/96); bar stays visible
  whenever results exceed 12, so the size picker is always reachable
- Show cards: poster image, rating badge, status indicator, genre tags,
  rounded corners (radius 10) for visual consistency with other pages;
  poster falls back to placeholder on empty OR broken/404 URL

═══════════════════════════════════════
SHOW DETAIL PAGE
═══════════════════════════════════════
- Hero section: poster, title, status tag, rating badge, year, age rating, language
- Tagline display
- Overview with 4-line clamp + expand/collapse toggle — toggle shown only
  when text actually overflows (ResizeObserver); resets on show change
- Genre tags
- Stat cards (shared StatCard tiles, same look as Dashboard): episodes
  watched, total watch time, seasons watched, first air year
- Show Details card: seasons, total episodes, episode runtime, popularity,
  vote count, first air date, last air date (formatted in UTC — no off-by-one-day
  west of UTC; invalid dates show –),
  networks, creators
- Watch History card: episode completion progress bar, season-by-season
  tracker with check/clock icons (watched / not watched)
- Cast: top 15 actors with overflow count
- Keywords: up to 20 tags
- Poster fallback: styled VideoCameraOutlined placeholder; also triggers
  on a broken/404 poster URL via <img onError>, not just an empty one
- "Show not found" now an Empty-based state (was a bare button)
- Back button falls back to /shows instead of browser history when
  there's no prior entry (direct link / page refresh)
- All 8 cards on the page: shadow + rounded corners (matches other pages)

═══════════════════════════════════════
STATISTICS PAGE
═══════════════════════════════════════
Stats Bar (10 cards):
- Shows Watched, Avg Rating, Unique Genres, Completion Rate,
  Episodes Watched, Top Genre, Top Network,
  Hours Watched, Minutes Watched, Years Watched
- Icon badge + colored top border + shadow (matches Dashboard stat cards)
- Hover text shows the formatted value (precision + unit); Hours Watched
  matches the Dashboard figure

14 Charts, grouped into 4 tabs (was one flat always-visible list):

Overview tab:
1. Top Genres — pie chart
2. Status Breakdown — donut chart
3. Language Breakdown — horizontal bar
4. Age Rating Distribution — vertical bar
5. Shows by First Air Year — vertical bar

Watch Time tab:
6. Top 10 by Watch Time — horizontal bar
7. Seasons Watched Depth — vertical bar (1/2/3/4+ seasons)
8. Watch Time by Decade — area chart with gradient fill
9. Watch Time by Release Year — vertical bar

Ratings tab:
10. Rating Distribution — vertical bar (0–10 buckets)
11. Rating vs Popularity — scatter plot
12. Completion Rate by Genre — horizontal bar (color-coded)

People & Networks tab:
13. Top Networks — horizontal bar
14. Top Actors & Creators — tabbed horizontal bar

Tab labels shorten below the sm breakpoint ("Watch Time" → "Time",
"People & Networks" → "People") to avoid clipping against antd's
tab-overflow trigger on narrow screens. All chart cards: shadow +
rounded corners (matches other pages).
Pie/donut legends fade in after the slice animation, including on
returning to the Overview tab (and stay visible if reduced motion is
switched off mid-visit). Status donut has fixed colors for
Returning Series, Ended, Canceled, In Production, Planned, Pilot; each
status uses the same color as a bar/slice and as a tag. Unknown
statuses get a theme chart color on every page (not Ended grey).
Watch-time tooltips formatted as "Xh Ym" (whole minutes).

═══════════════════════════════════════
THEMES
═══════════════════════════════════════
- Default Dark — indigo/purple on near-black
- Default Light — indigo on white, Tailwind-600 chart palette, pure black text
- Dracula — purple/pink on #282a36
- System (listed first, default when nothing is saved) — follows the OS
  prefers-color-scheme: Default Dark ↔ Default Light, switches live
- Theme choice (incl. System) persists across sessions via localStorage;
  an unknown saved value falls back to System
- Page root uses the theme's native color scheme + background — dark
  scrollbars / autofill / form controls in dark themes
- No flash on load: an inline boot script (generated from themes.ts at
  build time) applies the saved / OS theme colors before the app loads
- All theme colors via Theme object — no hardcoded dark/light values
- Every theme's chart colors and chart text meet WCAG AA contrast on its
  background (checked by a test)

═══════════════════════════════════════
CSV GENERATOR (series-search.py)
═══════════════════════════════════════
- Tkinter desktop app, queries TMDB API
- Search by show name, paginated results table with sortable columns
- Season selection panel (new seasons only, shows already-saved seasons)
- Saves: metadata, cast (top 5), keywords, age rating, poster URL,
  seasons watched, episodes watched, total runtime
- Re-adding a show updates existing row (no duplicates)
- A season whose episode fetch fails is skipped and reported (stays
  addable later), never saved as 0 episodes
- Search / paging buttons ignored while a page is loading; page counter
  only moves once a page loads; Next / Prev page through the last search
- Window stays responsive: all TMDB requests run in background threads
  (Loading... / Saving... status, Save disabled while saving)
- API key stripped from any error message
- Safe CSV writes: rewrites go through a temp file (never a half-written
  CSV), Excel's UTF-8 BOM is handled, a season already in the CSV is never
  counted twice, and any save error is shown in a dialog
- Writes public/tv_series.csv directly (path resolved from the script);
  unknown values written blank; appends follow the existing header

SIDEBAR / MOBILE NAVIGATION
═══════════════════════════════════════
Desktop (viewport ≥ lg breakpoint):
- Collapse trigger lives at the bottom of the Sider itself (moved off
  the Header — Header carries no menu-toggle button on desktop anymore)
- Manual collapse: icon-rail (80px), nav icons stay visible/clickable,
  hover shows tooltip with page name
- Content column capped at 1600px + centered — collapse only shifts
  margin above that width, consistent reflow feel across all 3 pages

Mobile (viewport < lg breakpoint):
- Sidebar/Sider fully hidden (collapsedWidth 0) — no hamburger, no
  drawer. Replaced by a fixed bottom nav bar: 3 icon+label buttons
  (Dashboard/Shows/Statistics), active route highlighted
- Respects the OS reduce-motion setting (live): no chart entry animations,
  pie legends shown at once (no fade), no Ant Design motion, bottom nav
  hides/shows instantly instead of sliding
- Bottom nav auto-hides on scroll-down (slides off via translateY,
  0.25s transition), reappears on scroll-up or near the top of page;
  always shown after navigating or on entering mobile width (resize /
  rotate) — layout-reflow scroll events don't re-hide it
- Content gets extra bottom padding so the last card/chart is never
  hidden under the bar even when it's visible

═══════════════════════════════════════
TECHNICAL
═══════════════════════════════════════
- Tests: Vitest unit tests (npm test), Playwright browser e2e with a
  synthetic CSV (npm run e2e, also in CI), Tk-driven check of
  series-search.py with TMDB faked (npm run test:gen, local)
- Static SPA — no backend, no build-time data
- CSV fetched at runtime via fetch() + PapaParse
- 100% React inline styles (no CSS files in src/)
- All Ant Design styling via ConfigProvider tokens
- All localStorage via settings.ts (tvdash-settings key)
- Filters, sort, theme persist across sessions (page size is per-visit)
- settings.ts tolerates corrupt JSON / blocked storage (never throws)
- Unknown values (blank / 0 / N/A year, rating, seasons, language, age
  rating) show '–' or are hidden — never "0", "★ 0.0" or an "N/A" tag;
  unrated / unknown-year shows sort last in Rating ↓ / Year ↓
- Seasons Watched counts unique seasons only ("1,1,2" = 2)
- Season count must be a whole number up to 1000 and episode runtime
  positive — otherwise treated as unknown ('–')
- CSV loading tolerates bad rows: a row with the wrong field count or a
  blank/invalid/duplicate TV ID is skipped instead of failing the whole
  file; broken quotes and missing required columns are fatal (a bad quote
  would swallow later rows), and so is every row being skipped
- Skipped rows show a dismissible warning banner above every page (first
  3 listed, rest in the console); reappears after a reload that still
  skips rows
- Empty tv_series.csv shows the Dashboard empty state, not a parse error
- CSV parsing is a pure module (parseSeriesCsv) separate from the fetch
  hook; a superseded or post-unmount request never updates state
- A failed reload clears data, so pages never show stale rows next to
  an error
- Data context throws if used outside its provider (no silent endless
  spinner); context lives in a component-free module so dev hot-reload
  never breaks an open page
- React.memo on ShowCard, ShowGrid, StatsBar, ChartsSection
- useDeferredValue for search input (non-blocking filter)
- Search filter persistence debounced 300ms (was synchronous per keystroke)
- Route chunks (Shows/Statistics/ShowDetail) idle-prefetched after mount
- Recharts ResponsiveContainer debounce={200} on all 14 charts
- cardShadow(isDark) shared helper in constants/ui.ts — one shadow
  formula used by Dashboard, FilterBar, ChartsSection, StatsBar, and
  Show Detail cards instead of 5x duplicated inline style objects
- Catch-all 404 route (NotFoundPage); trailing-slash and mixed-case URLs
  (/shows/, /Stats) get the right nav highlight + header title
- Show URLs accept canonical IDs only (/shows/0x1, /shows/01 → Show not found);
  a show with a blank name is titled "Untitled show"
- Browser tab title per route ("Dashboard · TV Dashboard", "<show name> ·
  TV Dashboard" on Show Detail, "Page not found · TV Dashboard") — same
  title as the header, which shows the series name on Show Detail
  ("Show Detail" while loading, "Show not found" for an unknown ID)
- Every navigation starts at the top of the page (Content scroll reset)
- RootErrorBoundary around the whole app: a crash in the shell (providers,
  router, layout) shows a plain recovery screen (works without the theme /
  antd, follows OS light/dark) with the error message, Reload and Reset
  saved settings — never a blank page, whatever was thrown
- ?reset on any URL clears saved settings (theme, filters, sidebar) before
  the app starts — first paint already uses the reset theme (no flash); the
  parameter is then removed, other params kept exactly as typed
- RouteErrorBoundary + Suspense inside AppLayout: page crash or failed
  lazy-chunk load shows ErrorState with reload; shell stays mounted
- Dev server binds 0.0.0.0 (vite.config server.host: true) — reachable
  from other devices on the same network, not just localhost
